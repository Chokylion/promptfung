## 2. Account settings
- Switch to a **Professional account → Creator** to see Reels insights.
- **AI-generated profile** label: OFF. These are hand-coded 2D animations, not AI-generated people.
- Keep **Show account suggestions** ON so the page gets discovered.

## 3. Posting plan
- Post **Reels** in order, **ตอนที่ 1 → 15** of ❄️ 15 วันก่อนหิมะตก, 1–3 per day (e.g. 12:00 and 20:00).
- Video: full-HD files from the GitHub Release `15-days-before-snow-winter` (`15-days-before-snow-epNN.mp4`).
- Caption: copy the matching block from [`brief.md`](brief.md). Format: hook with a number or question → one-line story → `🎧 พร้อมฟังต่อมั้ย → ตอนที่ N+1` → hashtags.
- Cover: pick a frame with the title card (first second) or use the episode poster.
- Turn on **"Also share to Facebook"** only if you want it there too.

## 4. Profile layout
- **Pin** ตอนที่ 1 (and later the newest episode) to the top of the grid.
- **Highlights** (cover = logo on black):
  - `❄️ หิมะ` — ตอนที่ 1–15 as stories
  - `🌊 ทริปรอดตาย` — new arc, add as episodes come out
  - `🛶 ท่าพระจันทร์` — 5 episodes
  - `🐰 อนาล็อก` — 2 shorts
- Story after every new episode: poster + "ตอนใหม่มาแล้ว" sticker + link sticker to the site.
